# Contributing

Try the walkthrough with a fictional project first. Report the assistant and version, operating system, command you gave, expected behavior, observed behavior, and a small sanitized example in a GitHub issue. Do not upload customer files or entire conversation histories.

Improvements should keep the four project files readable and preserve current-state precedence, citations, scoped writes, recoverable saves, and repeat-safe merges. Explain the user problem your change solves and verify the walkthrough. Run `python scripts/verify_package.py` from the repository root before submitting a pull request. Python is a maintainer check, not a requirement for using the protocol.

Contributions are provided under this repository's MIT license. Propose changes using your own work or clearly compatible licensed material. We do not promise response times or compatibility with every assistant.
